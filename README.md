## Lessons

Lessons about clean code I have learned:

- Don't repeat yourself. This means use functions effectively to call sections of code which are repeated throughout the
  task.
- Functions only have one job. This means that function should only do the job its required to do, not another that
  could be done.
- Always use docstrings. Completing docstrings easily allows the programmer to know what each function does quickly
  without going through all the code
